Smart Home Automation using ESP32 & React Native
Project Overview

This project demonstrates Smart Home Automation using ESP32, ESP-IDF, Bluetooth Low Energy (BLE) and React Native Mobile Application.

Features
Control 5 LEDs from mobile application
BLE communication between ESP32 and mobile app
Individual ON/OFF control
ALL ON / ALL OFF control
Real-time device interaction
Technologies Used
ESP32
ESP-IDF
Embedded C
Bluetooth Low Energy (BLE)
React Native
TypeScript
